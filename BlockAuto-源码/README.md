# BlockAuto 键鼠自动化平台（未发行 1.4 版）

Windows 桌面键鼠自动化工具。**键鼠动作是主角，积木只是把动作串起来的工具**：
打开就能「录一段 → 生成积木 → 一键运行」，需要判断循环时再从左侧拖积木增强。

v2.0 按《修改意见报告》重构：键鼠积木置顶、点击坐标一键记录（不用手填）、积木自由摆放、
界面紧凑、录制为主入口、最小化到托盘常驻；代码视图/断点/函数等开发者功能收进「专业模式」。

- 脚本后缀：`.block`（JSON，UTF-8）
- 运行平台：Windows 7 SP1+ / Windows 10 / 11（依赖 .NET Framework 4.5+，系统自带）
- 技术栈：C# 5 + WinForms + GDI+（**零第三方依赖**，用系统自带 `csc.exe` 编译）
- 目标机不需要安装编辑器：只需 `BlockRunner.exe` + `.block` + `templates/`

## 一、快速开始

```powershell
# 1. 编译（生成 bin\BlockAuto.exe / BlockRunner.exe / BlockAuto.Tests.exe）
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 2. 运行编辑器
.\bin\BlockAuto.exe

# 3. 直接打开某个脚本（双击 .block / 文件关联 / 快捷方式都走这条）
.\bin\BlockAuto.exe .\samples\keymouse_demo.block

# 4. 运行自测（167 项：引擎语义 / 数据流 / 递归 / 异常 / 调试 / 停止 / 结构校验 / JSON 往返 / 图像识别 / 定时 / 热键解析 / 打包 / AI 接口）
.\bin\BlockAuto.Tests.exe

# 5. 命令行运行脚本（独立运行器，不需要编辑器）
.\bin\BlockRunner.exe run .\samples\hello.block

# 6. 界面自检：启动主窗口、加载脚本、跑一次、截图、逐个打开弹窗后退出
.\bin\BlockAuto.exe --uicheck .\docs\screenshots\editor.png .\samples\hello.block
```

示例脚本：

| 文件 | 说明 |
|---|---|
| `samples/hello.block` | 纯逻辑：变量 + 循环 + 比较 + if/else + 日志，可直接运行 |
| `samples/logic_demo.block` | while / continue / break / 字符串拼接 / try-catch |
| `samples/recursive_find.block` | 需求文档中的“递归查找按钮”，识图 + 点击 + 递归 + 深度保护 |
| `samples/templates/submit.png` | 上面脚本使用的模板（放在脚本同级 `templates/` 下） |

## 二、目录结构

```
BlockAuto/
├─ build.ps1                 一键编译（csc + 共享源码）
├─ install-file-association.ps1  可选：把 .block 关联到 BlockRunner（当前用户）
├─ start-editor.cmd          双击启动编辑器
├─ bin/                      BlockAuto.exe / BlockRunner.exe / BlockAuto.Tests.exe
├─ samples/                  示例脚本 + 示例模板
├─ templates/                模板库示例
├─ docs/screenshots/         界面截图（自检生成）
└─ src/
   ├─ Shared/                编辑器与运行器共用
   │  ├─ Json.cs             无依赖 JSON 读写
   │  ├─ Model.cs            .block 数据模型 / 存取 / 校验 / 克隆
   │  ├─ Catalog.cs          积木目录（类型、端口、参数、颜色、分支）
   │  ├─ Engine.cs           积木解释执行引擎（唯一实现，三链路共用）
   │  ├─ Native.cs           截图 / 模板匹配 / 找色 / 键鼠输入 / 窗口
   │  ├─ Config.cs           全局配置与数据目录
   │  ├─ Scheduler.cs        编辑器定时调度
   │  └─ Hotkeys.cs          全局热键（RegisterHotKey）
   ├─ Editor/                编辑器 GUI（画布、面板、弹窗、代码视图）
   ├─ Runner/                BlockRunner 控制台运行器
   └─ Tests/                 无界面自测程序
```

### 三、P2/P3 详细说明

**AI HTTP 接口**（设置中勾选「启用 HTTP 接口」并填 Token 后生效）：

| 接口 | 白名单动作名 | 说明 |
|---|---|---|
| `POST /script/start` `{"script":"a.block","threshold":0.8}` | `script.start` | 启动脚本（复用同一引擎，同脚本并发互斥） |
| `POST /script/stop` `{"script":"a.block"}` | `script.stop` | 停止运行中的脚本 |
| `GET /script/status?script=a.block` | `script.status` | 运行状态、上次运行时间、活动会话数 |
| `POST /cap/screenshot` `{"region":"full"}` | `cap.screenshot` | 截图，返回 PNG base64 与坐标尺寸 |
| `POST /cap/findImage` `{"template":"templates/a.png","region":"full","threshold":0.8}` | `cap.findImage` | 识图，返回 found/x/y/confidence |
| `POST /cap/mouseClick` `{"x":100,"y":200,"button":"left","action":"click"}` | `cap.mouseClick` | 鼠标点击 |
| `POST /cap/keyType` `{"text":"你好"}` | `cap.keyType` | 键盘输入 |
| `GET /script/tree?script=a.block` | `script.tree` | 读取积木节点树 JSON |
| `PUT /script/tree?script=a.block` `{"tree":{...}}` | `script.tree` | 校验并写入 `.block` |
| `GET /log` | `log.read` | 最近日志行 |
| `GET /health` | `health` | 健康检查（同样需要 Token） |

> URL 路径是“小写+斜杠”风格，白名单动作名是“点号+驼峰”风格，两套名字容易配错。
> 从 1.0 起 `GET /health` 的 `actions` 字段会直接返回「路径 ↔ 动作名」对照表，设置页也写了提示，照抄即可。

安全机制：Token 必填（缺失返回 401）；白名单可禁用高危动作；「高危动作需人工确认」开启后，点击/输入会弹出确认框；接口只监听本机回环地址。

**操作录制**：录制只忠实记录键鼠时序，不识别画面、不自动加判断循环；坐标为屏幕绝对坐标，跨分辨率会错位（录制窗口内已提示改用识图积木）。可选「每个动作后加延时」「包含鼠标移动」。

**脚本打包**：输出 `<脚本名>-打包.zip`，内含脚本、模板、运行器、`双击运行.cmd`、`使用说明.txt`；接收方无需安装编辑器。

**联网**（默认全部关闭，设置中填写地址后才可用）：
- 更新检测：读取 `{"version":"1.1.0","notes":"...","url":"..."}`，本地比较版本号；
- 云脚本库：读取 `[{"name","url","description"}]`，可下载为 `.block` 并直接打开；
- 日志上报：只有勾选「允许上传日志」并手动点击才会上传最近 3 天日志。

## 四·六、识图改为独立模板 + 判断条件（v2.3）

v2.3 起，**识图不再是一个单独的积木**，而是「模板库 + 判断条件」：

- 模板统一放在脚本目录 `templates/`，可在「模板库」里导入、重命名、分组；
- 判断积木增加判断方式：`条件判断`（默认）/ **`有图片`**；
- 选「有图片」后填模板、相似度、识别区域：**找到就执行内部步骤，找不到就跳过**（有「否则」则走「否则」）；
- 右侧参数栏可直接「从模板库选择…」或「截取屏幕…」当场做模板；

## 四·八、鼠标点击＝识图+点击一步完成（v2.5，重点）

v2.4 把识图拆成了「判断条件 + 独立积木」，结果要「点某个按钮」得先放识图、再放点击，容易漏放。
v2.5 把识图**并回鼠标点击**：

- 独立的「识图」积木**从积木库移除**（保留类型定义，只为让旧脚本还能打开运行）；
- 鼠标点击积木新增参数：`coord_mode`（recorded / image / bound）、`template`、`region`、`threshold`、
  `on_fail`（retry / skip / error）、`retries`、`retry_delay`、`delay_after`；
- 参数抽屉与展开行里都有「📷 截图取图」：框选屏幕 → 直接存进脚本的 `templates/` → 这一步切到「自动识图」；
- 工具栏「📷 截图取图」：选中鼠标点击步骤时，截完直接填进这一步；没选中时存进模板库备用；

- 输出 `success / found / x / y / confidence`，后续步骤仍可连线使用；
- 旧脚本迁移：载入时若「识图积木 + 紧接着绑定它的鼠标点击」，自动合并成一步自动识图点击（模板、区域、阈值一起带过来）。

## 四·七、高分屏自适应（v2.4 起，v2.5 加强）

v2.4 起程序**始终按 DPI 感知运行**，不再依赖系统虚拟化；v2.5 继续加强：

- 200% 缩放下，截图分辨率就是 2880×1800（整屏），不会再“只截到左上角”；
- 鼠标坐标、框选坐标、识图结果都在同一套物理像素坐标系里，200% 下不会放大/错位；
- 界面按系统缩放自动放大（窗口、按钮、积木行、抽屉、窄条同步），文字不会被裁切；
- 自绘列表里的文字改为按设备像素直接绘制：200% 下不再经过等比拉伸，**文字清晰不发糊**；

- 旧版在高缩放比例下做的模板建议重截一次。

## 五、`.block` 文件格式

严格遵循《block文件JSON结构样例.md》，额外约定（向后兼容）：

1. **容器 children**：多分支容器（`if`、`try`）的 `children` 为“数组的数组”，顺序对应 `params.branches`（如 `["main","elif1","else"]` 或 `["try","catch"]`）；单分支容器（`while`/`for_*`）的 `children` 为普通积木数组。加载器两种形式都接受。
2. **数据来源**：`inputs[].from` 为空表示使用 `params` 字面值；非空为 `积木ID.输出端口`。
   - 纯数据积木（比较/逻辑/数学/拼接/读取变量）**每次引用都重新求值**，循环中不会读到上一轮旧值；
   - 函数调用积木若已执行过则复用结果，未执行时按需求值（支持 `n * fact(n-1)` 这种嵌套表达式）；
   - 动作积木（识图/找色/键鼠）执行后缓存输出，后续积木可连线消费。
3. **字面值与变量**：参数里写 `$变量名` 表示读取变量；字符串中出现 `${变量名}` 会在运行时插值（例如日志文本 `第 ${total} 轮`）。
4. **模板路径**：必须相对 `.block` 所在目录（保存/运行时校验，绝对路径判为结构错误），保证跨机器迁移。
5. **x/y**：仅编辑器排版使用，引擎忽略。

最小示例见 `samples/hello.block`。

## 六、编辑器使用要点

1. **添加积木**：左侧积木库拖到画布，或双击积木条目追加到当前选中块之后。
2. **调整顺序/嵌套**：拖动积木到目标位置（画布显示插入线）；拖到容器分支区域即可放入其中。
3. **连线**：从积木右侧输出引脚（圆点）拖到目标积木左侧输入引脚；右键积木 → “断开所有输入连线”。
4. **编辑参数**：双击积木，或在右键菜单选择“编辑参数”；识图积木可用“模板库/框选”选择模板与区域。
5. **断点与调试**：点击积木左侧红色圆点区域（右键菜单“设置断点”）→ 运行到该处暂停；工具栏 暂停/继续、单步、停止；运行中当前积木高亮，画布临时锁定以防改动。
6. **函数**：左侧“函数”区域新建/编辑/删除；进入函数后画布切换为该函数体，“← 返回主流程”切回。
7. **代码视图**：画布右上角“代码”按钮切换只读伪代码。
8. **模板库**：工具栏“模板库” → 导入图片 / 截取屏幕（框选）/ 新建分组 / 重命名 / 删除；模板保存在脚本目录的 `templates/` 下。
9. **热键 / 定时**：工具栏“热键”“定时任务”管理；定时到点直接调用同一引擎启动脚本。
10. **快捷键**：`Ctrl+N/O/S`、`Ctrl+Shift+S`、`Ctrl+Z/Y`、`Ctrl+C/V`、`F5` 运行、`F10` 单步、`Shift+F5` 停止、`Esc` 运行中急停。

## 七、BlockRunner（独立运行器）

```
BlockRunner.exe run <script.block> [--threshold 0.8] [--log log.txt] [--silent] [--no-esc]
BlockRunner.exe <script.block>
```

| 参数 | 说明 |
|---|---|
| `--threshold 0~1` | 覆盖脚本内的识图阈值 |
| `--log <文件>` | 追加写入指定日志文件 |
| `--silent` | 静默模式：隐藏控制台，日志写入文件（默认 `%APPDATA%\BlockAuto\logs`） |
| `--no-esc` | 关闭 ESC 急停监听 |

**退出码**：`0` 成功完成 / `1` 业务异常（除零、模板缺失、动作失败等）/ `2` 脚本结构错误（JSON 损坏、未知积木、非法连线、绝对模板路径）/ `3` 人工 ESC 停止。

双击关联（可选，当前用户级，不需要管理员）：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-file-association.ps1          # 安装
powershell -ExecutionPolicy Bypass -File .\install-file-association.ps1 -Uninstall # 卸载
```

## 十、约定与已知限制

- **DPI**：默认进程不做 DPI 感知（系统按逻辑像素缩放），使 UI 尺寸、截图坐标与鼠标坐标保持一致，跨缩放比例机器不会错位；需要物理像素时设置环境变量 `BLOCKAUTO_DPI_AWARE=1`。
- **识图缩放**：当前按 1:1 模板匹配（同一台机器截图生成的模板效果最好）；跨分辨率场景请使用“基于区域 + 相对坐标”或按目标机重新截取模板。
- **识别频率**：通过截图缓存（默认 250ms）限制，避免高频识图占满 CPU。
- **编辑器同一时间只允许一个“画布调试”运行**；不同脚本的通热键/定时后台运行可并存，同一 `.block` 并发会被跳过并记 WARN。
- **后台窗口截图**：代码已支持 `PrintWindow`，但默认走屏幕截图；对最小化/遮挡窗口的识别需要目标窗口支持渲染。
- **联网功能**：默认全部关闭，只有用户在设置中填写地址并由用户手动点击才会请求；不会后台自动联网。
- **AI 接口**：只监听 `127.0.0.1`，必须配置 Token；建议同时开启白名单与人工确认。
- 代码按 C# 5 语法编写（系统自带编译器仅支持 C# 5），因此不使用字符串插值、`?.`、`nameof` 等新语法。
