// 由积木树自动生成，仅供预览，修改不会同步回画布

主流程 {
  鼠标左键单击 自动识图 templates/submit.png（区域=active） 偏移 [0, 0]
  等待 0.5 秒
  输入文本 "hello BlockAuto"
  如果 有图片 templates/submit.png {
    日志 INFO "找到按钮，准备点击"
  }
  否则 {
    日志 WARN "没找到图片，跳过"
  }
}
